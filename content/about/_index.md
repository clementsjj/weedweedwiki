## Wiki Philosophy

To be a good wiki, pages should be:

- Editable by the community
- Editable in the browser
- Version history is viewable and accessible
- Navigate fluidly between links

The flat file structure with all pages in the same "articles" directory helps with fluid navigation. With wikis, links provide structure rather than directories. Frontmatter provides organizational metadata without separating related topics into different directories.

## Why weedweedwiki

1. Flows from the tongue
2. Pays homage to the ["wiki wiki shuttle"](https://en.wikipedia.org/wiki/Wiki_Wiki_Shuttle) that was the inspiration of the original ["wiki"](https://en.wikipedia.org/wiki/Wiki_Wiki_Shuttle)
    - Wiki = quick in the Hawaiian Language
    - "weed weed" is an offshoot of that idea
3. WWW pays homage to the world wide web
4. Cheap domain name 
5. "Weed" most commonly refers to Cannabis, but really it's any plant. All plants are sacred. And all weeds are just plants with a certain negative bias from humans. Here at WWW, there are no "weeds" in the negative sense, so we are reclaiming that word.

## Technology

This site is built with [Hugo](https://gohugo.io/), a fast static site generator. Content is written in Markdown and hosted on GitHub, enabling version control and collaborative editing.
