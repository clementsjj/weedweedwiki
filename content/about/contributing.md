## How to Edit Pages

On each page, you will see an "Edit" link near the top right. If you click on the link, it will take you to a GitHub page where changes can be made.

## Requirements

Since the contents of this wiki are stored and hosted on GitHub, you must have a GitHub account to make changes.

## Workflow

1. Click the "Edit" link on any page
2. Make your changes in the GitHub editor
3. Changes are made in a branch called `Edit`
4. Submit a pull request merging your changes from `Edit` into `Main`
5. Once reviewed and approved, your changes go live

## What to Contribute

- Fix typos and grammatical errors
- Add missing information to existing articles
- Create new articles on cannabis-related topics
- Improve article structure and readability
- Add sources and citations

## Guidelines

- Keep content factual and well-sourced
- Use a neutral, encyclopedic tone
- Follow the [Style Guide](style) for formatting
- Check the [Editing Guide](editing) for available shortcodes
