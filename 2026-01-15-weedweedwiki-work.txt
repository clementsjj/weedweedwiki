❯ so how does assets differ from static though? Wouldn't that also be at    
  'images/404.jpg'                                                          

● The difference:

  static/
  - Files copied as-is to output
  - static/images/404.jpg → accessible at /images/404.jpg
  - Reference directly by URL path in templates

  assets/
  - Files processed through Hugo Pipes
  - assets/images/404.jpg → only included if you call resources.Get "images/404.jpg"
  - Hugo generates the URL (via .RelPermalink)
  - Can resize, optimize, fingerprint, etc.

  So the final URL might look similar, but:
  - static: you hardcode the URL directly
  - assets: Hugo fetches and processes the file, then tells you the URL

  For your 404, either works. Assets is better if you later want to resize or optimize the image. Static is simpler if you just want to drop a file and reference it.
